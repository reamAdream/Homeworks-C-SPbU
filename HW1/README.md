# HW1 — Шаблонная сортировка на C++

## Описание проекта

В рамках домашнего задания реализована собственная шаблонная функция `mySort()` на основе алгоритма сортировки слиянием (Merge Sort).

Функция поддерживает пользовательский компаратор и используется для сортировки:

- `std::vector<int>` — по возрастанию;
- `std::vector<Point>` — по возрастанию квадрата расстояния до начала координат.

### Сложность алгоритма

- **Временная сложность:** O(n log n).
- **Дополнительная память:** O(n).

## Сборка и запуск

Проект разрабатывался в Microsoft Visual Studio 2026 с использованием CMake.

1. Открыть в Visual Studio папку `HW1`, в которой расположен `CMakeLists.txt`.
2. Дождаться завершения конфигурации CMake.

### Тестирование

1. Выбрать конфигурацию `x64-Debug`.
2. Собрать цель `test_sort`.
3. Запустить `test_sort.exe`.

Для Debug-сборки в `CMakeSettings.json` включён AddressSanitizer.

При успешном прохождении тестов программа выводит:

```text
Success!
```

### Бенчмарки

1. Выбрать конфигурацию `x64-Release`.
2. Собрать цель `bench_sort`.
3. Запустить `bench_sort.exe`.

Измерения производительности выполняются в Release-сборке с оптимизациями, без AddressSanitizer.

## Тестирование алгоритма

Для типов `int` и `Point` проверяются:

- пустой вектор;
- вектор из одного элемента;
- уже отсортированный вектор;
- вектор в обратном порядке;
- одинаковые и повторяющиеся элементы;
- случайные данные размером 10, 1 000 и 100 000 элементов.

Дополнительно проверяются отрицательные числа для `int` и сортировка точек по расстоянию до начала координат с пользовательским компаратором.

Для проверки корректности используются `assert()`, `std::is_sorted()`, `std::is_permutation()`, `std::equal()` и сравнение с эталонными результатами. Для больших векторов точек сохранность элементов проверяется после сортировки двух копий по координатам.

Тесты запускались в Debug-сборке с AddressSanitizer.

## Измерение производительности

Производительность `mySort()` сравнивается со стандартной функцией `std::sort()`.

| Тип данных | Количество элементов |
|---|---|
| `int` | 1 000, 10 000, 100 000, 1 000 000 |
| `Point` | 1 000, 10 000, 100 000, 1 000 000 |

Дополнительно проводится замер на уже отсортированном массиве из 100 000 целых чисел.

Каждый сценарий запускается **5 раз**. Программа выводит результаты измерений в миллисекундах и отношение времени `mySort` к `std::sort`.

Время генерации тестовых данных не включается в измерение времени сортировки.
