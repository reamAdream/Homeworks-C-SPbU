
# HW 1 — Шаблонная сортировка на C++

## Описание проекта

В рамках домашнего задания реализована собственная шаблонная функция `mySort()` на основе алгоритма сортировки слиянием (Merge Sort).

Функция поддерживает пользовательский компаратор и используется для сортировки:

- `std::vector<int>` — по возрастанию;
- `std::vector<Point>` — по возрастанию квадрата расстояния до начала координат.

### Сложность алгоритма

- **Временная сложность:** O(n log n).
- **Дополнительная память:** O(n).

## Сборка и запуск

Проект разрабатывался в Microsoft Visual Studio 2026 с использованием CMake.

### Тестирование

1. Открыть папку проекта в Visual Studio.
2. Выбрать конфигурацию `x64-Debug`.
3. Собрать цель `test_sort`.
4. Запустить `test_sort.exe`.

Для Debug-сборки в `CMakeSettings.json` включён AddressSanitizer.

При успешном прохождении тестов программа выводит:

```text
Success!
```

### Бенчмарки

1. Выбрать конфигурацию `x64-Release`.
2. Собрать цель `bench_sort`.
3. Запустить `bench_sort.exe`.

Измерения производительности выполняются в Release-сборке с оптимизациями, без AddressSanitizer.

## Тестирование алгоритма

Проверяются следующие случаи:

- Пустой вектор.
- Вектор из одного элемента.
- Уже отсортированный вектор.
- Вектор в обратном порядке.
- Одинаковые элементы.
- Отрицательные значения.
- Повторяющиеся элементы.
- Случайные массивы размером 10, 1 000 и 100 000 элементов.
- Сортировка объектов `Point` с пользовательским компаратором.

Для проверки корректности используются:

- `assert()`;
- `std::is_sorted()`;
- `std::is_permutation()`;
- сравнение результата с `std::sort()`.

Тесты также запускались в Debug-сборке с AddressSanitizer.

## Измерение производительности

Производительность `mySort()` сравнивается со стандартной функцией `std::sort()`.

### Размеры тестовых данных

| Тип данных | Количество элементов |
|---|---|
| `int` | 1 000 |
| `int` | 10 000 |
| `int` | 100 000 |
| `int` | 1 000 000 |
| `Point` | 1 000 |
| `Point` | 10 000 |
| `Point` | 100 000 |
| `Point` | 1 000 000 |

Дополнительно проводится тестирование уже отсортированного массива из 100 000 целых чисел.

Каждый сценарий запускается **5 раз**. Для сравнения используется среднее время выполнения в миллисекундах.

Время генерации тестовых данных не включается в измерение времени сортировки.
