# ДЗ 3. Разреженные матрицы

Умножение плотных и разреженных матриц на C++17. `DenseMatrix` из ДЗ2 хранит элементы по строкам в одном `std::vector<double>`. `SparseMatrix` хранит ненулевые элементы в `std::map<std::pair<int, int>, double>` с ключом `{строка, столбец}`.

Виртуальный `Matrix::mul()` выбирает реализацию по типу левого множителя. Внутри метода `dynamic_cast` определяет тип правого множителя. Поддерживаются Dense×Dense, Sparse×Dense, Dense×Sparse и Sparse×Sparse. В смешанных случаях результат хранится в `DenseMatrix`, а в Sparse×Sparse — в `SparseMatrix`.

В Sparse×Sparse для каждого ненулевого `A(i, k)` вызов `lower_bound({k, 0})` находит начало обхода строки `k` в B. Вклады накапливаются прямо в словаре результата. Если сумма становится нулевой, запись удаляется.

## Сборка и запуск

Проверяемая конфигурация — Windows x64 с MSVC, CMake 3.20 или новее и Ninja. Для тестов нужен установленный компонент C++ AddressSanitizer.

Команды выполняются из папки HW3 в x64 Native Tools Command Prompt for Visual Studio.

```bat
cmake -S . -B out/build/x64-Debug -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build out/build/x64-Debug --target test_sparse_matrix
.\out\build\x64-Debug\test_sparse_matrix.exe
```

В Debug для `test_sparse_matrix` включён `/fsanitize=address`. После успешного прогона программа печатает `Success!`.

```bat
cmake -S . -B out/build/x64-Release -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build out/build/x64-Release --target bench_matrix
.\out\build\x64-Release\bench_matrix.exe
```

Бенчмарк собирается в Release с `/O2`. AddressSanitizer включается только для тестовой цели в Debug. В Visual Studio можно открыть папку HW3, выбрать конфигурацию из `CMakeSettings.json` и соответствующую цель запуска.

## Тесты корректности

- Проверяются размеры, чтение, запись и обнуление элемента, исключения при неверных размерах и индексах.
- Ручные примеры умножения матриц 2×3 и 3×2 проверяют разреженное и оба смешанных умножения.
- Отдельно проверяются умножение на единичную и нулевую матрицы и исключение при несовместимых размерах.
- Случайный тест создаёт плотные и разреженные представления одних и тех же матриц 7×5 и 5×9. Sparse×Sparse и обе смешанные комбинации сравниваются с Dense×Dense по элементам с абсолютным допуском `1e-9`.

## Бенчмарк

Матрицы имеют фиксированный размер **200×200**. Для каждой заданной плотности обе реализации получают одинаковые входные значения. Генератор `std::mt19937` использует `seed = 42`, а распределение Бернулли задаёт вероятность заполнения каждой ячейки.

Для каждой плотности измеряется время одного вызова `mul()` для Dense×Dense и Sparse×Sparse, включая создание результата. Генерация входов, подсчёт контрольных сумм и вывод таблицы находятся вне замеров. В таблице приведены результаты одного запуска **x64-Release** с `/O2`. Ускорение равно времени Dense, делённому на время Sparse.

| Заданная плотность | Dense×Dense, мс | Sparse×Sparse, мс | Ускорение |
| --- | ---: | ---: | ---: |
| 50% | 1,3114 | 89,3166 | 0,01× |
| 10% | 1,1239 | 6,2300 | 0,18× |
| 1% | 1,1238 | 0,0806 | 13,94× |
| 0,1% | 1,0696 | 0,0026 | 411,38× |

При печати с шестью знаками после точки обе контрольные суммы по всем четырём плотностям совпали. Dense×Dense и Sparse×Sparse дали `-41125.745730`.

При 10% быстрее Dense×Dense, а при 1% Sparse×Sparse выигрывает в 13,94 раза. На проверенных плотностях смена лидера наблюдается между **1% и 10%**.
