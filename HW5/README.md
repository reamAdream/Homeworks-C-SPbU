# ДЗ 5. HTTP server/client на WinSock2

Сервер и текстовый клиент на C++17 для Windows. Сетевое взаимодействие реализовано с помощью WinSock2 без сторонних HTTP-библиотек.

## Возможности

- Сервер принимает HTTP/1.1 GET-запросы и отдаёт файлы из папки, указанной при запуске.
- Для найденного файла возвращает `200 OK`, для отсутствующего — `404 Not Found`. В ответе указан `Content-Length` в байтах.
- Файлы читаются в бинарном режиме. Для `.html` и `.htm` используется `text/html`, для остальных файлов — `application/octet-stream`.
- Сервер обрабатывает клиентов в отдельных потоках и проверяет, что путь к файлу не выходит за пределы корневой папки.
- Клиент формирует GET-запрос и печатает полученный ответ целиком, включая заголовки.

Сервер слушает `127.0.0.1:8080`. Запрос `/` соответствует файлу `index.html` в корневой папке.

## Структура

- `src/server.cpp` — запуск сервера и приём подключений.
- `src/client.cpp` — текстовый клиент.
- `Include/http.hpp`, `src/http.cpp` — обработка запросов и формирование ответов.
- `tests/test_http.cpp` — тесты разбора запроса, путей и формирования ответа.
- `www/` — примеры файлов для сервера.

## Сборка

Требуются Windows, CMake версии 3.20 или новее и компилятор MSVC с поддержкой C++17. В **Developer PowerShell for Visual Studio** из папки проекта:

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build
```

Для этого примера также нужен Ninja. В Debug для цели тестов включён AddressSanitizer.

## Запуск

Запусти сервер, передав папку с файлами:

```powershell
.\build\server.exe "F:\C++\HW5\www"
```

Укажи путь к своей папке, если проект расположен в другом месте. Пока сервер работает, открой в браузере `http://127.0.0.1:8080/about.html`.

В другом терминале можно запустить клиента:

```powershell
.\build\client.exe 127.0.0.1 8080 /about.html
```

Клиент принимает три аргумента: адрес сервера, порт и путь. Пример подключения к внешнему серверу:

```powershell
.\build\client.exe example.com 80 /
```

Клиент выводит сырой HTTP-ответ; при `Transfer-Encoding: chunked` служебные данные частей также видны в выводе. Для остановки сервера прерви его выполнение в терминале или Visual Studio.

## Тесты

```powershell
ctest --test-dir build --output-on-failure
```

Тесты запускаются в Debug: используются `assert`, которые в Release могут быть отключены. Они проверяют разбор первой строки запроса, подготовку и сравнение путей, а также формирование заголовков и тела ответа, включая пустое тело и нулевой байт.
